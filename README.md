# Don Diego 🍰

Proyecto web para **Don Diego**, un emprendimiento de panadería y repostería.

El objetivo del proyecto es desarrollar una plataforma donde los usuarios puedan explorar productos, consultar información y realizar pedidos de forma sencilla.

## 🚀 Funcionalidades

* 🏠 Página de inicio
* 🧁 Catálogo de productos
* 🔎 Visualización de productos
* 🛒 Carrito de compras
* 👤 Gestión de usuarios
* 📦 Gestión de pedidos
* 💳 Sistema de pago
* 📱 Diseño adaptable a distintos dispositivos

## 🛠️ Tecnologías

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
* Git
* GitHub

## 📁 Estructura del proyecto

```text
DonDiego-Panaderia-Pruebas/
│
├── controllers/
├── models/
├── views/
├── config/
├── public/
│   ├── css/
│   ├── js/
│   └── img/
│
├── database/
├── .gitignore
└── README.md
```

El proyecto utiliza una estructura basada en el patrón **MVC (Model-View-Controller)** para mantener el código organizado y facilitar el trabajo en equipo.

## 🌿 Flujo de trabajo con Git

Las ramas principales del proyecto son:

```text
main
  ↑
develop
  ↑
├── facu
├── mati
├── cony
└── cano
```

* `main`: versión estable y final del proyecto.
* `develop`: rama donde se integran los cambios del equipo.
* `facu`, `mati`, `cony`, `cano`: ramas individuales de desarrollo.

Los cambios se realizan en las ramas individuales y posteriormente se envían mediante **Pull Requests** hacia `develop`.
